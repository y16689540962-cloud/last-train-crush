# 末班车的心动 · Last Train Crush

> 一场需要十四个夜晚才敢开口的暗恋。浪漫叙事互动游戏（可玩 Demo：第 1-3 程）。

**▶ 立即试玩：<https://y16689540962-cloud.github.io/last-train-crush/>**

- 单文件网页游戏，手机竖屏 / 桌面浏览器均可，双击即玩、无需安装
- 全程程序化合成音效（右上角开关），零外部资源
- Demo 约 10 分钟，两条结局分支；完整版规划为 14 程（一个季节的暗恋）

## 运营说明（面向测试者）
- 点击「走进车厢」开始；第 2 程需要**长按**屏幕 2 秒偷看速写本
- 便签字块可以自由拼句——你的每一次选择都会被温柔记住
- 测试反馈请提 Issue 或直接发给作者
